🎯 A proposta do curso

Mostrar, de forma simples e pausada, o caminho que leva você do "usuário que clica" ao profissional que entende, lê e escreve o que o ArcGIS faz por trás, usando a inteligência artificial como copiloto, sem precisar virar programador.

Para quem é este curso

É para você se…

  • Já usa ArcGIS Pro no dia a dia, mas nunca programou
  • Repete as mesmas tarefas toda semana e sabe que dá para automatizar
  • Já tentou Python e travou na primeira mensagem de erro
  • Quer usar IA no trabalho com GIS, mas não sabe por onde começar
  • Trabalha em prefeitura, consultoria, cadastro, meio ambiente ou agro

Não é para você se…

  • Nunca abriu um software de GIS (comece pelo básico antes)
  • Já é desenvolvedor e procura um curso avançado de programação
  • Espera um curso de "apertar botão" sem entender o porquê

O que você vai aprender

Sete módulos com aulas curtas. Cada uma termina com algo funcionando na sua tela.

MÓDULO 01

Tudo é texto

O que o ArcGIS esconde: JSON de web map, simbologia, pop-ups e GeoJSON. Você vai abrir, ler e entender o "código" dos seus próprios mapas.

✅ Resultado: ler o JSON de uma simbologia e alterá-la sem clicar
MÓDULO 02

Python do zero, no ritmo de quem vem do GIS

Variáveis, listas, laços e funções explicados com exemplos de camadas, campos e feições, nada de exemplo abstrato.

✅ Resultado: seu primeiro script que percorre uma lista de camadas
MÓDULO 03

arcpy: automatizando o que você faz clicando

Como cada ferramenta do ArcGIS vira uma linha de código. Geoprocessamento em lote, cursores e atualização de campos.

✅ Resultado: processar dezenas de camadas com um único comando
MÓDULO 04

Sem extensão, sem problema

Declividade, reclassificação, densidade e krigagem com bibliotecas Python livres, para quando você não tem Spatial ou Geostatistical Analyst.

✅ Resultado: um mapa de declividade e uma krigagem feitos só com Python
MÓDULO 05

IA como copiloto

Como pedir um script à IA, rodar, ler a mensagem de erro e corrigir. O método que transforma a IA numa parceira de trabalho, e não numa caixa-preta.

✅ Resultado: um script feito em parceria com a IA, do pedido ao resultado
MÓDULO 06

O Notebook "Run All"

Organizar o trabalho em notebooks prontos para rodar: parâmetros no topo, mensagens de início e fim, saída salva em .txt e entrega organizada.

✅ Resultado: um modelo de notebook reutilizável para qualquer análise
MÓDULO 07 · PROJETO FINAL

Do dado bruto ao mapa pronto

Uma análise completa de ponta a ponta: importar, processar, analisar, adicionar as camadas ao projeto, simbolizar e salvar o .aprx, tudo por script.

✅ Resultado: um projeto completo para mostrar no portfólio
